# やどかりんAI 学習キット

住まいの悩みの文章から「ペットと住みたい」「家賃をおさえたい」などの条件を読み取る、自分たちで作ったAIです。
学習はこのフォルダの `train.py`（Python）で行い、できた `yk-model.json` をサイトに置くと、見ている人のブラウザの中で動きます。

- 料金: 0円（サーバーもAIサービスも使わない）
- 速さ: 1回 0.05ミリ秒くらい
- 大きさ: 約120KB
- 動く端末: スマホ・PC・Meta Quest のブラウザすべて

## しくみ（発表用の説明）

1. 文章を正規化する（全角→半角、カタカナ→ひらがな、大文字→小文字）
2. 文字を1〜3文字ずつのかたまり（文字N-gram）にばらす。例: 「ねこ」→「ね」「こ」「ねこ」「^ね」…
3. 18個の条件それぞれについて、ロジスティック回帰で「その条件が書かれている確率」を出す
4. 確率が境目（0.45）以上の条件を「読み取った条件」とする（1つの文に複数あってもよい）

数字（「8万円まで」）・間取り（「2LDK」）・駅からの分数（「徒歩5分」）・地名は、AIではなくルール（正規表現）で読みます。
「どんな悩みか」はAI、「具体的な数字や名前」はルール、という分担です（チャットボットでよく使う「意図」と「スロット」の考え方）。

## 使い方

```
pip install numpy
python train.py
```

- `yk-model.json` … できたモデル（となりに `site` フォルダがあればその中に、なければこのフォルダに書き出す）
- `report.md` … 成績の表とまちがえた文の一覧
- `metrics.json` … 成績の数字（グラフを作るとき用）

できた `yk-model.json` をサイトのフォルダに上書きしてアップロードすれば反映されます。
※ `sw.js` の `CACHE_NAME` の数字を1つ上げると、利用者の端末でも確実に新しいモデルに入れ替わります。

## データ

| ファイル | 中身 | 使い方 |
|---|---|---|
| `data/labels.tsv` | 18個の条件の名前と意味 | 条件を増やすときはここに行を足す |
| `data/train.tsv` | 学習用の文（手書き） | 自由に足してよい |
| `data/dev.tsv` | 調整用の文 | 設定を試すときの成績確認に使う |
| `data/test.tsv` | 最終テスト用の文 | **最後の確認にだけ使う。この結果を見てデータや設定を直さない** |
| `data/survey.tsv` | アンケートで集めた本物の文（あなたたちが作る） | あれば自動で学習に足される |

1行の形は `条件（カンマ区切り）<TAB>文` です。条件がない文は `-` にします。

```
pet,single	一人暮らしで猫を飼いたい
-	こんにちは
```

## アンケートで精度を上げる（卒業研究としておすすめ）

1. クラスの人や家族に「部屋探しで困っていること・希望」を自由に書いてもらう（1人3〜5文）
2. 集めた文に、自分たちで条件をつける（2人で別々につけて、意見が分かれたものは話し合うと正確になる）
3. 半分を `data/survey.tsv`（学習用）、残り半分を新しいテスト用にする
4. `python train.py` を実行し、ルール方式との成績の差を比べる

いまのテスト文は学習用の文と同じ人（開発側）が書いたので、本物の利用者の文より読みやすい可能性があります。
**別の人が書いた文でテストした結果**を出せると、研究としての信頼度が上がります。

## 実験用の設定

| 環境変数 | 意味 | 例 |
|---|---|---|
| `DEV_ONLY=1` | テストの成績を見ずに、調整用データだけで評価する | 設定を試すときは必ずこれを付ける |
| `SEED=3` | 乱数の種（つなぎ文の作り方が変わる） | 結果のぶれを見るときに変える |
| `PRUNE=1.0` | これより小さい重みを捨てる（大きいほどモデルが軽い） | |
| `MIN_COUNT=4` | 何回以上出てきた文字のかたまりを使うか | |
| `AUG3=0.35` | 3つの文をつなぐ割合 | |
| `FIXED=1e-4,0.45` | 交差検証を飛ばしてペナルティと境目を固定（実験を速くする） | |
| `OUT=...` | モデルの書き出し先 | |

## わかっている弱点

- 1つの文にたくさんの条件が入っていると、一部を見落とすことがある（文が長いほど1つ1つの手がかりが弱くなるため）
- 「家賃は10万円まで」のように予算を書いただけでも「家賃おさえめ」と読むことがある
- 学習データにない言い回しや、皮肉・否定（「ペットは飼わない」）は苦手
