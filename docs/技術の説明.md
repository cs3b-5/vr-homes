# VR Homes 技術の説明（先生の質問対策メモ）

聞かれたら、まず1行目を言って、続けて聞かれたら「くわしく」を話す。

## 全体のしくみ
- **サイト**: HTML・CSS・JavaScript だけで作った Web サイト。GitHub Pages で公開していて、アプリのインストールはいらない。
- **サーバー**: AWS の **Lambda**（Python）が API。物件・ユーザーは **DynamoDB**、写真や実写のデータは **S3** に保存する。
- **流れ**: ブラウザ → Lambda（関数URL）→ DynamoDB / S3。写真は Lambda が出した「署名つきURL」でブラウザから S3 に直接アップロードする（Lambda を重いデータが通らない）。

## 3D・VR
- **Babylon.js** … ブラウザで3Dを描くライブラリ（Microsoft が作っている、WebGL を使う）。間取りのデータから、床・壁・ドア・窓をその場で組み立てて3Dにしている。
  - くわしく: 間取りデータは 50px = 1m。部屋は長方形か多角形（斜めの壁もOK）。壁に開口（ドア・窓）を切り抜いて作る。
- **WebXR** … ブラウザから VR ゴーグル（Meta Quest など）を使うための標準のしくみ。Babylon.js の機能で、ボタン1つで VR の中に入れる。
- **スマホVR** … 画面を左右2つに分けて描き、スマホのジャイロ（傾きのセンサー）で向きを変える。段ボールなどの安いゴーグルで見られる。
- **日当たり** … 物件の緯度・経度と月・時刻から太陽の高さと方角を計算して、窓から入る光と影を出す。

## 実写（ガウシアンスプラット）
- **ガウシアンスプラット（3D Gaussian Splatting）** … 写真や動画から部屋を3Dにする新しい方法。三角形の面ではなく、色のついた「ぼんやりした小さな粒」を何十万個も並べて、写真のような見た目を出す。
  - くわしく: 粒ごとに 位置・大きさ・向き・色・透明度 を持つ。スマホの Scaniverse、PC の RealityScan → Brush などで作る。
- **SPZ** … ガウシアンスプラットを小さく圧縮するファイル形式（Niantic が公開）。.ply の約10分の1の大きさになるので、Webで配るのに向いている。サイトに .ply を入れると、ブラウザの中で .spz に変換してから保存する。
- **軽くする工夫** … 重さは粒の数にほぼ比例するので、端末ごとに数を決めて（スマホ10万・Quest 15万・PC 35万）、「不透明度×見かけの大きさ」が大きい＝目立つ粒から残す。かくかくしたら解像度を自動で下げる。
- **水平と大きさ** … 撮ったデータは傾いていたり単位がメートルでなかったりする。粒の集まりから床・天井・壁の平らな面を探して（RANSAC という方法）床を水平にし、間取りの天井の高さに合わせて大きさをそろえる。

## 位置合わせ（実写と間取りを重ねる）
- **自動の位置合わせ** … ①床の高さ → ②壁の向き → ③間取りの壁と一番重なる位置、の順に合わせる。
  - くわしく: ①床の高さは、下のほうで粒が一番多い高さ。②壁の向きは、腰〜頭の高さの粒を上から見て、壁が縦横にそろう角度を探す。③間取りの壁に対して「4方向 × 位置」を総当たりして、実写の壁が間取りの壁にいちばん重なる所を選ぶ。「撮った部屋」を選ぶとその部屋の中だけで探すので速くて正確。
  - 長方形の部屋は 180° 逆でも重なってしまうことがあるので、最後に人が窓やベンチの位置で確かめる（「90°回す」で直せる）。

## 間取りエディタ
- **間取り図の画像から自動で作る** … 画像の線（壁）を見つけて部屋の形にし、**tesseract.js**（ブラウザで動く文字認識 OCR）で「洋室」「6帖」などの文字を読んで、部屋の名前と大きさ（縮尺）を決める。
  - くわしく: 「6帖」のような広さが読めたら、その部屋の面積から 1m が何ピクセルかを逆算して縮尺を合わせる（帖数が読めないときはドアの幅から推測し、「長さを合わせる」で手で直せる）。

## 地図・場所
- **Leaflet ＋ OpenStreetMap** … 物件の地図。住所から緯度・経度を出すのは OpenStreetMap の Nominatim、周りの駅などは Overpass API で調べる。

## ログイン・安全
- **ログイン** … パスワードはサーバー（Lambda）で確かめる。ログインすると、サーバーの秘密の鍵で署名した「セッショントークン」が返り、そのあとはそれで本人か確かめる。
- **秘密の値** … 鍵やコードは Lambda の環境変数にだけ置いて、公開しているコード（GitHub）には入れていない。

## PWA
- **PWA（ホーム画面に追加）** … manifest.json と Service Worker（sw.js）で、スマホのホーム画面からアプリのように開ける。一度開いたファイルを保存しておくので、2回目から速い。

## よくある質問
- **なぜ Unity ではなく Web？** … インストールなしで、スマホ・PC・Quest のどれでも URL を開くだけで使えるから。不動産のお客さんにアプリを入れてもらうのはハードルが高い。
- **どのくらい正確？** … 間取りは間取り図の寸法どおり。学校のデモは教室の実測 9.22m を基準に縮尺を合わせた。実写はスキャンした形そのもの。
- **重くない？** … 間取りの3Dは軽い。実写は点の数を端末に合わせて減らし、スマホでも動くようにしている。
