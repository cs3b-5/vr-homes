# VR Homes 実機チェック表

公開サイト: https://cs3b-5.github.io/vr-homes/
確かめた人が `[ ]` を `[x]` にして、気になったことは「メモ」に書く。ダメだったところは **何をしたら・どうなったか** を書く（スクショがあると助かる）。

## 確かめる前に
- サイトは**新しい版**で見る（古い画面が出るときは、ページを2回読み込み直す）。
- 確かめる物件: ①トップの **「学校の1号館を体験する」**（間取り＋ホールの実写） ②トップの「この部屋に入ってみる」（サンプルの部屋）
- 端末の情報をメモ欄に書く（例: iPhone 13 / iOS 18 / Safari）。
