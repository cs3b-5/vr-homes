# VR Homes 展示会アンケート案（Googleフォーム用）

1/22 の中間発表と 2/4 の展示会で使う。**1分で答えられる長さ**（全7問、必須は6問）。
Googleフォームに写して、できたURLをサイトに入れる（下の「サイトに入れる方法」）。

---

## フォームの説明文（いちばん上に書く）

> よりよくするために、1分ほどのアンケートにご協力ください。名前やメールアドレスは聞きません。

## 結果のまとめ方（発表用）
- Q2・Q3・Q6 は平均点と「4・5をつけた人の割合」をグラフにする。
- Q4 は多い順に棒グラフ。Q5 は円グラフ（「しなかった＋少し」の割合を言う）。
- Q1 と Q5 を組み合わせて「端末ごとの酔いやすさ」を見ると、考察に使える。
- Q7 はよく出た意見を3つくらいにまとめて「今後の改善」に書く。

## サイトに入れる方法
1. Googleフォームを作って「送信」→ リンクのボタン → URL をコピー（「URLを短縮」でもOK）。
2. `index.html` の `id="he-survey"` の行にある `href=""` の `""` の中に URL を貼る。
   ```html
   <a class="he-survey" id="he-survey" href="https://forms.gle/xxxxxxxx" target="_blank" rel="noopener" hidden>…
   ```
3. URLが入っていると、トップの「スマホ・PC・Meta Quest のブラウザで…」の下に **「アンケートに答える（1分）」** が出る（空のあいだは出ない）。
4. `sw.js` の `CACHE_NAME` の数字を1つ上げて、PR → main にマージ。
5. 展示ではフォームのQRコードも紙で置いておくと答えてもらいやすい（Googleフォームの「送信」→ リンク から作れる）。
